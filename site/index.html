Read Japanese games on your Steam Deck.

A Decky Loader plugin that reads the text box on screen, looks up every word, and sends the ones you want to Anki — all in Gaming Mode, all on the Deck.

Download latest release Install guide

Work in progress. It's a personal project — some flows are rough, and things may change.

At the press of a button

  1. Press L5

    While a line of Japanese is on screen. A brief outline flashes over the text box.

  2. 2

    The line is read on the Deck

    The text box is screenshotted and OCR'd locally. No internet needed.

  3. 3

    Move over a word

    The Quick Access menu opens with the line split into words. D-pad or tap to see a definition.

  4. 4

    Send words to Anki

    Queue the ones you want, then scan a QR code with your phone to import them into AnkiMobile or AnkiDroid.

Features

  • Never leave the game

    Lookup happens in the Quick Access menu. Close it with B and keep playing.

  • Works offline

    OCR engine and dictionary are downloaded once and stay on the Deck. Nothing is sent anywhere.

  • Real dictionary

    Ships with Jitendex, built on JMdict. Any Yomitan-format dictionary works too.

  • Anki mining

    Cards carry the word, reading, meaning, the full sentence, and the game's name. Export to your phone over Wi-Fi.

  • Per-game capture area

    Drag a box over the text box once; the plugin remembers it for that game.

  • Your choice of button

    L4, R4, L5, or R5. Give a second button its own area — one for the text box, one for the whole screen.

Install

No computer needed. About ten minutes on the Deck, plus a few minutes of downloads on first launch.

  • A Steam Deck on Wi-Fi
  • About 600 MB free
  • AnkiMobile or AnkiDroid on a phone (only for Anki)
Screenshot: Desktop Mode with decky.xyz open in the browser and the installer running

Install Decky Loader

Skip this if you already have Decky.

  1. Hold the Steam button → Power → Switch to Desktop.
  2. Open a browser, go to decky.xyz, download the installer and run it. Choose the release version.
  3. Switch back to Gaming Mode when it's done.
Screenshot: the GitHub release page on the Deck with the .zip asset highlighted

Download the plugin zip

On the Deck, open the latest release and download vn-lookup-vX.Y.Z.zip. Desktop Mode's browser is easiest, but Gaming Mode's works too.

It lands in Downloads.

Screenshot: Decky settings, General tab, with the Developer Mode toggle at the bottom

Turn on Developer Mode

The plugin isn't on the Decky store, so it's installed from the zip.

  1. Press … (Quick Access) → the Decky tab (plug icon).
  2. Press the gear icon → General.
  3. Turn on Developer Mode at the bottom.
Screenshot: the Developer tab with "Install from zip" and the file browser showing Downloads

Install from zip

  1. A new Developer tab appears in Decky settings. Open it.
  2. Press Install from zip, browse to Downloads, and select the file.
  3. Wait for it to finish, then check the Decky tab for Japanese Lookup.

If it doesn't show up right away, restart the Deck.

Screenshot: the plugin's panel on first open, showing the four download buttons

First launch

Open … → Decky → Japanese Lookup. With Wi-Fi on, press each download button and wait for it to finish before the next:

Install lookup runtime~60 MB
Download dictionary (Jitendex)~70 MB
Install OCR runtime~400 MB
Download OCR models~22 MB

The OCR runtime takes a few minutes. The buttons disappear once everything is in place. Start a game and press L5.

Questions

Does it need internet?

Only for the one-time downloads on first launch, and for exporting to Anki over your local Wi-Fi. Reading and lookup run entirely on the Deck.

Which games does it work with?

Anything with a single text box on screen — visual novels are the target. It doesn't handle dialogue logs or several speakers at once. If a game puts its text somewhere unusual, drag the capture area over it once and the plugin remembers it for that game.

Pressing L5 does nothing.

A game has to be running — captures don't work from the Steam menus. Check the capture area's drop-down is set to L5 and not None. If Advanced settings → Show debug info doesn't say Controller: hooked and PipeWire: ok, restart the Deck.

It says "No text found" or "Accuracy low".

The box probably doesn't sit exactly over the text. Open the plugin with the game's text box on screen, press Change area, and drag the box over it. Very small or stylised fonts can also read poorly.

The QR code won't open on my phone.

Phone and Deck need to be on the same Wi-Fi (not mobile data or a guest network). The link expires after about five minutes — press Export via QR code again for a fresh one.

Japanese Lookup doesn't show up in Decky after installing.

Restart the Deck and check again. Sideloaded zips aren't Decky's officially supported path and can be flaky; if it still won't appear, install from source instead.

Can I use Yomitan instead of the built-in lookup?

Yes. Every captured line is also shown on a local page at localhost:8766 and copied to the clipboard, so Yomitan in Firefox (Desktop Mode) can pick it up. Details are in the README.

How much space does it take, and how do I remove it?

About 800 MB once the OCR engine and dictionary are downloaded. Advanced settings → Delete downloaded data frees that space but keeps the plugin. Uninstalling from Decky's plugin list removes everything, including your Anki queue — export it first.

Where does the dictionary data come from?

The plugin ships no dictionary. On first launch it downloads Jitendex, which is built from JMdict by the EDRDG, Tatoeba example sentences, and JmdictFurigana. Full attribution and licences are in the README.
